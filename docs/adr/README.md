# Architecture Decision Records

Every significant architectural decision is recorded as `NNNN-short-title.md` with
the following structure:

```text
# NNNN. Title

Status: accepted | superseded by ADR-NNNN | rejected
Date: YYYY-MM-DD

## Context
## Decision
## Consequences
## Alternatives
```

A recorded decision is never changed by editing the file. Write a new ADR instead
and mark the old one as superseded.
