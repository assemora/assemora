# create-assemora

This name is held for the [Assemora](https://github.com/assemora/assemora) scaffolder,
which is not released yet. Installing this package gets you a command that tells you so.

Assemora runs from a checkout today:

```bash
git clone https://github.com/assemora/assemora.git
cd assemora
pnpm install
pnpm demo
```
