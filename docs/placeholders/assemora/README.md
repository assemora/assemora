# assemora

This name is held for the [Assemora](https://github.com/assemora/assemora) umbrella
package — the one call that assembles an application (SPEC.md §9) — which is not
released yet. Importing this package throws with a link rather than pretending to work.

Assemora runs from a checkout today:

```bash
git clone https://github.com/assemora/assemora.git
cd assemora
pnpm install
pnpm demo
```
